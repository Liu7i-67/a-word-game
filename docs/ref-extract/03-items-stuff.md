# 03 - 物品/装备全量提取（stuff_app，20 件）

注意：**无价格/买卖字段**（无经济系统实现）；「获取途径」只能从说明文案推断。

## 1. 公共字段（stuff/models.py:25-43）

| 字段 | 说明 |
|---|---|
| name | 物品名称 |
| icon | 图标（文件名 = 原版游戏图标资源 id） |
| illustrate | 说明（原文全文保留于下表） |
| level | 最低使用等级 |
| is_tradable | 1=可交易 0=不可交易 |
| weight | 负重（0 = 不占负重，如礼包/乾坤袋/引路蜂） |

**类型枚举**（stuff/models.py:8-14）：1=武器 2=护甲 3=药品 4=消耗品 5=任务物品
**品质枚举**（stuff/models.py:15-22）：1=普通 2=精良 3=稀有 4=完美 5=史诗 6=传奇
