## 2. NPC 模型（npc/models.py）

| 字段 | 说明 |
|---|---|
| name | varchar(64) |
| location | 所在地（后台只读，admin.py `readonly_fields=['location']`，即由系统维护） |
| city | 所在城市（choices 动态取自 Map 表，npc/models.py:8-10） |
| default_place | 默认所在地 |
| bio | 简介 text(1024) |

**落位校验**（npc/models.py:22-29）：`default_place` 必须存在于城市 places，否则 `ValueError("该城市没有%s这个地点！")`；
若 `location` 为空则自动设为 `default_place`。**location 与 default_place 分离 → 规划了 NPC 游走/移动机制**（当前坐标 vs 默认坐标）。

旧表备份 `_npc_npc_old_20230311`（空）：字段只有 name/location/default_place/bio —— 说明 city 字段是 2023-03-11 之后才加的，多城市是后期规划。
